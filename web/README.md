# Web Part

Веб-часть проекта находится в разработке.

## Планируемый стек

- Laravel
- Vue.js

## Планируемый функционал

- загрузка изображений пользователем;
- вывод результатов распознавания;
- отображение распознанных продуктов и КБЖУ на 100 г;
- регистрация и авторизация пользователей;
- личный кабинет;
- история загрузок;
- ручное формирование рациона питания по продуктам из базы данных.
