# Nutrition Project

Система распознавания продуктов питания на изображениях с использованием **YOLOv11** и **Python** с дальнейшей интеграцией в веб-приложение на **Laravel + Vue.js**.

## Назначение проекта

Проект разрабатывается в рамках выпускной квалификационной работы и предназначен для:

- распознавания продуктов питания на изображении;
- определения нескольких продуктов на одном фото;
- отображения результатов детекции на изображении;
- вывода справочной информации о пищевой ценности продукта;
- подготовки к интеграции с веб-приложением для ведения рациона питания.

На текущем этапе в репозитории представлена **ML-часть проекта**.  
Веб-часть находится в разработке.

---

## Основная идея

Пользователь загружает изображение с продуктами или блюдом, после чего система:

1. распознаёт продукты на изображении;
2. выделяет найденные объекты bounding boxes;
3. выводит список обнаруженных продуктов;
4. показывает справочные значения **КБЖУ на 100 г** для каждого продукта из локальной базы данных.

### Важно
В текущей версии проекта **не выполняется автоматический расчёт массы продукта по изображению**, так как такая задача требует дополнительных методов и не обеспечивает достаточную точность в рамках данного проекта.

Для расчёта реального рациона питания предполагается, что пользователь в дальнейшем сможет **указывать массу продуктов вручную** в личном кабинете веб-приложения.

---

## Реализованный функционал

### ML-модуль
- подготовка и разбиение датасета на `train / valid / test`;
- обучение модели детекции на базе **YOLOv11**;
- валидация модели;
- тестовый inference на пользовательских изображениях;
- вывод результатов распознавания с визуализацией;
- вывод КБЖУ на 100 г из локальной JSON-базы.

### Планируемая веб-часть
- загрузка изображений через интерфейс сайта;
- отображение результатов распознавания;
- регистрация и авторизация пользователей;
- личный кабинет;
- история загрузок;
- формирование приёмов пищи и дневника питания;
- расчёт КБЖУ на основе введённой пользователем массы продуктов.
